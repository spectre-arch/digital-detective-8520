What is a Branch?
A branch is a separate line of development in a Git repository. It allows us to make changes without affecting the main branch.

 What is a Pull Request?
A Pull Request (PR) is a request to merge changes from one branch into another. It allows others to review the changes before they are merged.

 Why are Branches Useful?
- They allow developers to work on features separately.
- They keep the main branch stable.
- They make it easier to experiment and fix bugs.

 Why are Pull Requests Useful?
- They allow code review before merging.
- They help team members discuss changes.
- They reduce the chance of mistakes entering the main branch.
