Git operation                 What does it do ?

Check repository status.      git status shows which files have been modified, staged, or are untracked.
Stage selected changes.       git add filename selects a file and prepares its changes for the next commit.
Create a commit.              git commit -m "message" saves the staged changes as a version in Git history.
View commit history.          git log --oneline displays the recent commits in a short format.


Difference Between Staging and Committing

Staging means selecting the changes that I want to include in my next commit. It is done using the git add command.

Committing means permanently saving those staged changes as a recorded version in the local Git repository. It is done using the git commit command.
