Difference between compiler and interpreter.
--> A compiler translates the source code into another form, often machine code, before the program runs. An interpreter executes the program at runtime, processing its instructions as it goes. C is commonly compiled, while Python is commonly described as an interpreted language. However, Python implementations such as CPython also compile code into bytecode before executing it.
