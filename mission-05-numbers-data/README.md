# Mission 5 – Numbers and Data

## Objective
Understand number systems, convert numbers between decimal, binary and hexadecimal, and learn how computers store text.

## Tasks Completed

- **Task 5.1:** Converted decimal, binary and hexadecimal numbers by hand.
- **Task 5.2:** Verified number conversions using Python.
- **Task 5.3:** Created a Python number converter.
- **Task 5.4:** Learned about ASCII and UTF-8 character encoding.

## Files Created

- `task_5_1.md` – Manual number conversion steps.
- `task_5_2.md` – Python conversion verification.
- `verify_conversions.py` – Python verification program.
- `number_converter.py` – Decimal to binary and hexadecimal converter.
- `task_5_3.md` – Converter test results and explanation.
- `task_5_4.md` – Text encoding notes.

## Commands and Tools Used

- `python3` – Run Python programs.
- `bin()` – Convert decimal numbers to binary.
- `hex()` – Convert decimal numbers to hexadecimal.
- `int()` – Convert binary and hexadecimal strings to decimal.
