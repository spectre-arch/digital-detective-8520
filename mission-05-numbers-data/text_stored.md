2. Explain in one or two sentences why a computer needs an encoding standard to store text.
-->. A computer understands and stores data in binary form (0s and 1s). An encoding standard assigns numbers to characters so that computers can store, read and display text correctly.

3. Name one example of a character that is not part of basic ASCII.
-->  The Indian Rupee symbol (₹) is an example of a character that is not part of basic ASCII. It can be represented using UTF-8.
