What happens when you open a website?
--> When I enter a website address in my browser and press Enter, the following steps take place:

Browser: The browser receives the website address entered by the user.

DNS Lookup: The browser uses DNS (Domain Name System) to find the IP address associated with the website's domain name.

Network Connection: My computer sends a request through the network, usually using a router, to reach the website's server.

Server: The server receives the request and processes it. It finds the information needed for the webpage.

Response: The server sends the requested data back to my browser using network protocols such as HTTP or HTTPS.

Display: The browser receives the response, processes the webpage's files and displays the website on the screen.
