# Task 7.1 – Network Concepts

| Concept | Explanation | Example |
|---|---|---|
| LAN (Local Area Network) | A network that connects devices in a small geographical area. | Home Wi-Fi or school computer lab |
| MAN (Metropolitan Area Network) | A network that connects devices across a city or a large campus. | A network connecting different college campuses in a city |
| WAN (Wide Area Network) | A network that connects computers over large geographical areas. | The Internet |
| DNS (Domain Name System) | DNS translates a website's domain name into its IP address. | Translating google.com into an IP address |
| Router | A router connects different networks and forwards data between them. | A home Wi-Fi router |
| Protocol | A set of rules that devices follow to communicate with each other. | HTTP, HTTPS and TCP |
| Packet Switching | Data is divided into smaller packets that travel across a network and are reassembled at the destination. | Sending a message over the Internet |
| Client-Server | A client requests a service or information, and a server provides it. | A browser requesting a webpage from a web server

## Conclusion

Computer networks allow devices to communicate and share information. Different network types, protocols, routers and DNS work together to make Internet communication possible.
