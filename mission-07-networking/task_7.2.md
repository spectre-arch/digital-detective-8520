1. Explain what a connectivity test helps you check.
-->. Command used:

ping -c 4 example.com

A connectivity test checks whether my computer can communicate with another device or server over a network.

The ping command sends small packets of data to a destination and checks whether replies are received. It also shows the response time.

2. Explain what information a DNS lookup displays.
--> nslookup example.com

A DNS lookup finds the IP address associated with a domain name.

It displays information such as the DNS server used and the IP address returned for the domain.

3. Describe the role of DNS when you enter a website name in a browser.
--> DNS stands for Domain Name System. It translates human-readable domain names into IP addresses that computers use to identify servers on a network.

For example, when I enter example.com in my browser, DNS helps find the server's IP address so the browser can connect to it.
