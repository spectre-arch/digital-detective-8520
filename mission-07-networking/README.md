# Mission 7 – How Computers Communicate

## 1. Mission Objective

To understand how computers communicate with each other through networks and how websites work over the Internet.

## 2. Work Completed

- **Task 7.1:** Learned about LAN, MAN, WAN, DNS, Router, Protocol, Packet Switching and Client-Server.
- **Task 7.2:** Learned how to test network connectivity using `ping` and perform DNS lookups using `nslookup`.
- **Task 7.3:** Explained the steps involved when a user opens a website in a browser.

## 3. Commands and Tools Used

| Command | Purpose |
|---|---|
| `ping -c 4 example.com` | Tests network connectivity |
| `nslookup example.com` | Finds the IP address associated with a domain |
| `touch` | Creates a file |
| `open -a TextEdit` | Opens a file in TextEdit |

## 4. What I Learned

- LAN, MAN and WAN are different types of networks.
- DNS converts domain names into IP addresses.
- A router connects networks and forwards data.
- Protocols are rules that allow devices to communicate.
- Data travels across networks in packets.
- A browser acts as a client and requests information from a server.
- When a website is opened, DNS lookup, network communication and server responses take place.
