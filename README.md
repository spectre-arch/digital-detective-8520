## How to Run the Number Converter

1. Open the Terminal.
2. Navigate to the numbers and data mission folder:

   ```bash
   cd mission-05-numbers-data
   ```

3. Run the Python program:

   ```bash
   python3 number_converter.py
   ```

4. Enter a decimal number when prompted. The program displays its binary and hexadecimal forms.
