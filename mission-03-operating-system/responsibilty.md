1. Process Management :- The OS manages running programs and decides how they use the CPU. Ex :- Running Safari and VS Code at the same time.

2. Memory management: The OS manages RAM and allocates memory to programs. Ex :- Manages RAM and gives memory to different programs. | Giving RAM to a browser when it opens.

3. Device management: The OS controls hardware devices such as keyboards, printers and speakers. Ex :- Managing a keyboard, mouse and printer.

4. File management: The OS helps create, save, organise, rename and delete files. Ex :- Saving a document inside a folder.

5. User interface / shell: The OS provides ways for users to interact with the computer, such as a graphical desktop or Terminal. Ex :- Using macOS desktop or Terminal.

6. Security and permissions: The OS controls access to files and protects the system from unauthorised access. Ex :- Requiring a password to access an account.
