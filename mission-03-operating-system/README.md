# Mission 3 — Understand the Operating System

## 1. Task / Objective
The objective was to explore the operating system, running processes, storage, file paths and permissions, and understand the responsibilities of an operating system.

## 2. Work Completed
- Explored macOS system information.
- Checked available and used storage.
- Observed running processes and their PIDs.
- Learned about absolute and relative paths.
- Explored file permissions.
- Studied the six main responsibilities of an operating system.

## 3. Commands / Tools Used
- `sw_vers` — Displays macOS version information.
- `whoami` — Displays the current account username.
- `df -h /` — Displays storage information.
- `top -l 1` — Displays a snapshot of system activity.
- `ps -ax` — Displays running processes.
- `pwd` — Displays the current directory path.
- `cd ..` — Moves to the parent directory.
- `ls -l` — Displays detailed file information and permissions.

## 4. My Understanding
I learned that an operating system manages computer hardware and software resources. It manages processes, memory, devices, files, user interaction, security and permissions.

I also understood how processes use PIDs, how paths locate files and how permissions control access.

## 5. Difficulties Faced
Understanding the difference between absolute and relative paths and learning file permission symbols.

## 6. How I Resolved Them
I practised Terminal commands and studied examples of file permissions and directory paths.
