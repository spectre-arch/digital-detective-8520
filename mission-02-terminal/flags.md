1. What are flags?
--> Flags are options added to commands to change their behaviour or provide additional information.

2. All of the flags commands are :-

ls :- it lists all the content of the folder or a directory but usually not the hidden ones.
ls -l :- it lists a detail listing of all the contents 
ls -la :- it displays all the hidden contents
head -5 :- it shows the first 5 output 

3. What does the pipe symbol does ?
--> A pipe (|) sends the output of one command as input to another command. Baiscally it will take the output of one command and then it will give that output as an input to another command.
