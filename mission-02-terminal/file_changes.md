1. What is the difference between replacing a file's contents and adding text to the end?
--> Replacing a file's contents removes the existing content and writes new content. Adding text to the end keeps the existing content and adds new information after it.

2. What is the difference between copying a file and moving a file?
--> Copying creates another version of the file while keeping the original file in its location. Moving transfers the file to another location or changes its name.

3. What information does the current-directory display provide?
--> The current-directory display shows the full path of the folder in which the Terminal is currently working.

4. Why is a directory-listing operation useful?
--> A directory-listing operation helps us see the files and folders present in a directory. It makes file management and navigation easier.
