# Mission 2 — Become Comfortable with the Terminal

## 1. Task / Objective
The objective of this mission was to learn basic Terminal operations, manage files and directories, understand command flags and pipes, and explore package managers.

## 2. Work Completed
- Practised basic Terminal commands.
- Created folders and text files.
- Copied and renamed files.
- Learned to append text and create backups.
- Explored command flags and pipes.
- Checked Homebrew and its installed packages.

## 3. Commands / Tools Used
- `pwd` — Displays the current directory.
- `ls` — Lists files and folders.
- `cd` — Changes directories.
- `mkdir` — Creates directories.
- `touch` — Creates empty files.
- `echo` — Writes text to files.
- `cat` — Displays file contents.
- `cp` — Copies files.
- `mv` — Moves or renames files.
- `head` — Displays the first few lines.
- `brew` — Manages software packages on macOS.
- Git and GitHub — Used for version control and uploading the mission.

## 4. My Understanding
I learned how to navigate through directories and manage files using Terminal. I understood the difference between replacing and appending file contents, copying and moving files, and using flags to modify commands. I also learned how pipes connect commands and how package managers simplify software management.

## 5. Difficulties Faced
Understanding the difference between the `>` and `>>` operators and learning how pipes work were initially confusing.

## 6. How I Resolved Them
I practised the commands in a separate folder and observed their outputs to understand how they work.
