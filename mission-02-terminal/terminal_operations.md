# Mission 2 — Become Comfortable with the Terminal

## Task 2.1 — Explore Basic Terminal Operations

1. Current Directory :- PWD
It displays the full path of the directory in which the Terminal is currently working.
I observed that it displayed the location of my Mission 2 folder.

2. Directory listing :- ls
It displays all the content present in the folder.
I observed that it showed me all the contents of my Mission 2 folder.

3. Detailed listing :- ls -l
It displays files and folders with detailed information such as permissions, owner, size and modification date.
I observed that it displayed additional information about each file and folder.

4. Change directory :- cd ..
It moves from the current directory to its parent directory.
I observed that my current location changed to the parent directory.

5. Create directory :- mkdir
It creates a new folder 
I noticed it created a new a folder.

6. Create empty file :- touch practice
It created a new a file named practice.
I observed that it created a new file named practice.

7. Copy file :- cp practice/sample.txt practice/copy.txt
Creates a copy of the original file with a different name.
I noticed a duplicate file named copy.txt was created.

8. Move / Rename file :- mv practice/copy.txt practice/renamed.txt
Moves a file to another location or changes its name.
I noticed that the  copied file was renamed to renamed.txt.

9. Display file contents :- cat practice/sample.txt
Displays the contents of a text file in the Terminal.
I noticed it displayed the contents of the original file. Since the file was empty, nothing appeared.
