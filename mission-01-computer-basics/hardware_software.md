HARDWARE :- Hardware refers to the physical parts of a computer that we can touch.

SOFTWARE :- Software refers to programs and applications that run on a computer.

HARDWARE          PURPOSE

Keyboard.        Is used to type
Mouse.           Is used to move the cursor
Monitor.         Displays information
SSD.             stores information

SOFTWARE.         TYPE.               PURPOSE

MacOS.            Operating System.   Manages the computer.
Google Chrome.    Application.        Used to browse the internet.
Visual Studio Code  Application.      Used to type or edit code.
Disk Utility.      Utility.           Helps manage storage disks.
