 Trace an Activity Using IPOS

Activity: Searching something on Google.

| Stage | What happens? | Hardware |

| Input | I type a search query. | Keyboard |
| Processing | The computer processes my search request. | CPU and RAM |
| Output | Google displays the search results. | Monitor |
| Storage | Data can be saved on the computer. | SSD |

**Explanation:**

When I search something on Google I enter text using the keyboard. The computer processes the request and then the results appear on the screen. Data can also be stored on the computer.
